# Best CEO — Getting Started Guide

The official getting-started guide for [Best CEO](https://best.ceo): from your first scan to a marketing department on autopilot.

**Live page → https://dresden-xyz.github.io/best-ceo-guide/**

Share that link with anyone — it opens in any browser, no account or login needed.

## What's in here

| File | Purpose |
|---|---|
| `index.html` | The entire guide — markup, styles, and content in one self-contained file |

There's no build step, no dependencies, and no framework. The only external request the page makes is to Google Fonts for Archivo and IBM Plex.

## Updating the guide

Edit `index.html` and commit to `main`. GitHub Pages redeploys automatically, usually within a minute.

To edit directly in the browser: open `index.html`, click the pencil icon, make your changes, and commit.

## Previewing locally

Open `index.html` in a browser, or serve it to match how Pages will behave:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment

Served by GitHub Pages from the `main` branch, root folder. Settings live under **Settings → Pages**.

## Contents

The guide covers: what Best CEO is, the first 10 minutes, how to read your report, the executive team, the skill catalog, autopilot setup, the REST API, a 30-day plan, and plan comparison.
